# AI-Assisted RCSA Intelligence Agent

## Objective
An AI-assisted workflow that supports Operational Risk Managers and Business Owners in conducting Risk and Control Self-Assessments (RCSA).

## Core capabilities
- Process and risk identification
- Historical loss-event analysis
- Control assessment and challenge
- Inherent and residual risk assessment
- Evidence-based reporting
- Human review and approval

## Technology
Python, LangGraph, OpenAI API, Pandas, RAG.

## Governance principle
The agent provides recommendations and structured assessments. It does not make final risk decisions or approve RCSAs.
